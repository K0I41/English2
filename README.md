# AI健康チェックWebアプリ

## 概要

大学の授業で、3人チームで開発したAI健康チェックWebアプリです。

睡眠時間、運動時間、食事、体調、気分、生活リズム、集中度の7項目について5段階で回答すると、AIがその日の生活習慣を振り返り、短いアドバイスを返します。

このアプリは医療診断を目的としたものではなく、日々の生活習慣を振り返るための一般的なアドバイスを提供するものです。

## 開発目的

Webアプリケーション開発とAI API連携の流れを実践的に学ぶことを目的として開発しました。

単にHTML/CSS/JavaScriptで画面を作るだけでなく、フロントエンドからバックエンドAPIへデータを送信し、OpenAI APIを用いて回答内容に応じた文章を生成する構成にしました。

## 主な機能

* 健康状態に関する7項目の質問フォーム
* 各項目を5段階で回答
* 回答内容をスコア化
* Express APIへの回答データ送信
* OpenAI APIを用いた健康チェック結果の文章生成
* 結果画面でのスコアとAIコメント表示
* APIキー未設定時や通信失敗時のエラー表示

## アプリの流れ

1. トップ画面から健康チェックを開始
2. 7項目の質問に回答
3. 回答内容をExpressサーバーへ送信
4. サーバー側でOpenAI APIへ回答内容を送信
5. AIが生活習慣に関する短いアドバイスを生成
6. 結果画面にスコアとAIコメントを表示

## 工夫した点

### 1. フロントエンドとバックエンドを分けた構成

フロントエンドだけで完結させるのではなく、ExpressでAPIを作成し、フォームの回答データをバックエンドへ送信する構成にしました。これにより、APIキーをフロントエンドに直接書かず、サーバー側で管理できるようにしました。

### 2. OpenAI APIとの連携

ユーザーの回答内容をそのままAIに送るのではなく、質問内容・回答内容・スコアが分かる形に整形してからOpenAI APIへ送信するようにしました。これにより、AIが回答内容を理解しやすくなり、より自然なアドバイスを返せるようにしました。

### 3. 健康系アプリとしての安全性への配慮

健康に関する内容を扱うため、AIが医療診断や病名の断定を行わないようにプロンプトを設計しました。あくまで生活習慣を振り返るための一般的なアドバイスとして返答するようにしています。

### 4. エラー処理

OpenAI APIキーが設定されていない場合や、回答データが不足している場合に、ユーザーへ分かりやすいエラーメッセージを返すようにしました。

## セットアップ方法

### 1. リポジトリをクローン

```bash
git clone リポジトリのURL
cd English2
```

### 2. パッケージをインストール

```bash
npm install
```

### 3. 環境変数を設定

`.env.example` をコピーして `.env` を作成します。

```bash
cp .env.example .env
```

Windows PowerShellの場合は、以下でも作成できます。

```powershell
Copy-Item .env.example .env
```

`.env` にOpenAI APIキーを設定します。

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-5-mini
```

※ `.env` には本物のAPIキーを記載するため、GitHubには公開しないようにしています。

### 4. アプリを起動

```bash
npm start
```

起動後、ブラウザで以下にアクセスします。

```text
http://localhost:3000/front.html
```

## 注意事項

このアプリは医療診断を目的としたものではありません。
AIが返す内容は、生活習慣を振り返るための一般的なアドバイスです。体調に不安がある場合は、医療機関や専門家に相談してください。

また、OpenAI APIを利用するため、実行にはOpenAI APIキーが必要です。
